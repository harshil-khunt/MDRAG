## ➤ PROJECT OBJECTIVE:- **Font: Arial 18**

**Font: Arial 13**

The main objectives of the project are:-

• To design and develop an intelligent document management system using Retrieval-Augmented Generation technology.

• To implement multi-format document processing supporting PDF, DOC, DOCX, and TXT files with OCR capabilities.

• To develop an automated URL crawling system with sitemap support and change detection for web content.

• To create a natural language question-answering interface that provides accurate answers with source citations.

• To build a scalable system supporting multiple AI providers (Google Gemini and OpenAI) with workspace isolation.

• To make an economical and user-friendly document intelligence platform.

---

## ➤ INTRODUCTION:-

• One of the most common challenges in information management is that users must manually search through multiple documents to find specific information, making the process time-consuming and inefficient. Because of the lack of intelligent search, users must rely heavily on keyword matching to perform simple queries, which can result in significant cognitive work and missed information.

• A comprehensive AI-powered document management system is presented. The system is electronically controlled and processes documents using advanced natural language processing. The MDRAG system presented has the potential to be used by organizations, educational institutions, and individuals managing large document collections.

• A closed loop RAG pipeline for intelligent retrieval and generation has been demonstrated to provide accurate answers and lessen the occurrence of information overload, in addition to minimizing the demand for manual document reading.

## ➤ METHODOLOGY:-

• The system is designed and developed using modern web technologies. Frontend is built using React with TypeScript for type safety.

• The backend is developed using Node.js with Express.js framework. For document processing, inputs are taken from file uploads and URL submissions, and content is processed accordingly with text extraction and chunking. The system entirely operates on AI-powered embeddings and similarity search.

• Arduino UNO microprocessor is used for controlling and actuating prosthetic arm.

• MongoDB database is used for storing metadata and document chunks. Redis is used for job queue management with BullMQ.

• In this project we have developed a Retrieval-Augmented Generation pipeline to provide accurate answers to user queries based on uploaded documents. For RAG implementation we have used Pinecone vector database and transformer-based embeddings.

• A scalable, efficient and intelligent question-answering system is provided to users. Google Gemini and OpenAI APIs are used along with vector similarity search to provide contextual answers.

• The MDRAG system is an advanced version of document management which is very comprehensive and scalable such that it becomes user-friendly and hence it increases the adoption rate of AI-powered document systems.
